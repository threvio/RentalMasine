# Rental Machine - Front-End Practice Project

## Overview
This is a responsive, static website built for a fictional heavy equipment rental company ("Rental Machine"). I created this repository as a school/practice project to strengthen and showcase my core web development skills before moving on to more complex frameworks.

## Technologies Used
* **HTML5:** Semantic structure and layout.
* **CSS3:** Custom styling, Flexbox/Grid layouts, custom variables, and responsive design.
* **JavaScript:** DOM manipulation for interactive elements (e.g., mobile navigation toggle).
* **FontAwesome:** Scalable vector icons for the UI.

## Features
* Fully responsive layout (Mobile-friendly).
* Interactive navigation menu.
* Clean, dark-themed modern UI design.
* Structured sections including Hero, Services, Testimonials, and Footer.

## About This Project
This repository serves as a portfolio piece demonstrating my foundational skills in Front-End development. It focuses strictly on vanilla web technologies (Vanilla JS, pure CSS) to ensure a strong understanding of the basics.
